# Вкладка «Информация о долге» на карточке техники

## Что нового

На странице `/vehicle/[id]` появилась новая вкладка **«Информация о долге»**
(видна, если к технике привязан клиент — текущий арендатор или клиент из
справочника). В ней:

- градиентная карточка с общей суммой задолженности и временем последней
  синхронизации с ravapi.eu;
- разбивка: начислено всего / осталось оплатить / уже оплачено;
- расшифровка задолженности построчно (дата, за что, сумма, статус —
  «Оплачено» / «Просрочено» / «Частично», статус вычисляется из реальных
  цифр quota/remainingPayoff, которые уже отдаёт `/api/debtors/[id]/debt-details`);
- заметка по долгу и чек-бокс «связались с клиентом» (использует уже
  существующий `PATCH /api/debtors/[id]`);
- история обращений + отправка напоминания клиенту (использует уже
  существующий `POST /api/debtors/[id]/notify`);
- ссылки `tel:` / `mailto:` и переход в карточку клиента.

Бэкенд для расшифровки долга, заметок и SMS уже был в проекте — просто не
был подключён к странице техники. Новая логика на сервере (`vehicle/[id]/page.tsx`)
сопоставляет клиента техники (`Client.phone` либо `Vehicle.renterPhone`) с
записью `Debtor` из снапшота ravapi.eu по нормализованному номеру телефона
(последние 9 цифр — см. `src/lib/phone.ts`), т.к. форматы хранения номеров
могут отличаться (`+48 601 234 567` vs `601234567` и т.п.).

## Изменённые / новые файлы

```
src/lib/phone.ts                          — НОВЫЙ: сравнение телефонов в разных форматах
src/lib/i18n/translations.ts              — новые ключи переводов (ru/pl/uk)
src/components/VehicleDetail.tsx          — новая вкладка "Информация о долге" + DebtTab
src/app/vehicle/[id]/page.tsx             — подгружает client + подобранного debtor
src/app/api/vehicles/[id]/route.ts        — GET теперь включает client
```

## Как применить

Скопируйте файлы поверх соответствующих путей в вашем репозитории (структура
папок сохранена), закоммитьте и запушьте — Railway пересоберёт проект
автоматически.

```bash
npm install
npx prisma generate
npm run build   # локальная проверка перед пушем
```
